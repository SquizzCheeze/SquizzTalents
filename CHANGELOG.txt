SquizzTalents - Changelog
=========================


V1.0
----

First release.

Loadouts:

- One list of your Blizzard loadouts and your own saved builds. Blizzard
  loadouts are read live from the game and never copied; your own builds are
  stored as talent import strings, so there is no cap on how many you keep.
- Click a build to apply it. The result is confirmed by the game rather than
  assumed, and anything that could not be applied is reported. Applying is
  refused, with the reason shown, in combat, during an active Mythic+ key, or
  whenever the game says talents cannot be changed.
- Save current build, and a right-click menu for every build: apply, use for
  this content, tags, icon, rename, delete. Blizzard loadouts can be deleted
  from here too (Blizzard's talent window only notices while it is open; if it
  still lists a deleted loadout, /reload).
- Import and export with Blizzard's own talent codes, the same ones the talent
  window and build sites use. Import a code into SquizzTalents (any spec of
  your class) or as a new Blizzard loadout (current spec, within Blizzard's
  loadout limit); the code is checked as you paste it. Export any build from
  the right-click menu to share it.
- Icon picker for any build (right-click > Set icon): a grid of every icon
  with a search box. Search talents and spells of your class by name, your
  specs and this season's Mythic+ dungeons, or browse the full icon catalogue;
  a spell ID or icon ID typed into the search finds that icon directly.
- Saved builds made on an older talent tree are marked Outdated, with the
  reason in the tooltip. Update to current talents refreshes one with your
  active talents and keeps its name, icon, tags and content mappings. Delete
  outdated removes every outdated build for your spec at once.

Reminders:

- A reminder on entering a dungeon, raid, delve, battleground or arena, on
  slotting a keystone, and on a ready check. It only appears when your active
  build is not the one chosen for that content, never during an active key,
  and waits for combat to end.
- Choose builds per content: one difficulty of an instance, the whole
  instance, or every dungeon / raid / delve / battleground / arena. The most
  specific choice wins. Set it from the reminder's "Remember for" dropdown or
  by right-clicking a build.
- The entry check retries for up to 15 seconds after loading, because some
  content (delves especially) is reported late.

Other:

- Styled to match SquizzFrames: dark flat windows with a title bar, flat
  buttons, switches and highlights in your class colour.

- Settings page under Options > AddOns > SquizzTalents (/sqt config):
  reminder switches and your content choices for the current spec.
- Release notes once per update, shared with the other Squizz addons so they
  queue instead of overlapping. /sqt notes shows them again.
- /sqt debug opens a copyable diagnostic dump. /sqt remind runs the reminder
  check on demand; /sqt testoutdated saves a deliberately outdated build for
  testing.
